# Transcript — نوشتن با صدا، کاملاً محلی

روی **start.cmd** دوبار کلیک کنید. مرورگر خودکار در `http://127.0.0.1:8765` باز می‌شود. پنجرهٔ پایتون را باز نگه دارید و صبر کنید تا مدل آماده شود. نیازی به نصب یا دانلود مدل جدید نیست.

۱. زبان گفتار را انتخاب کنید (پیش‌فرض فارسی).
۲. «شروع صحبت» را بزنید و به مرورگر اجازهٔ میکروفون بدهید.
۳. صحبت کنید. بعد از حداقل ۸ ثانیه، مکث‌ها باعث ارسال بخش صدا برای پردازش می‌شوند؛ گفتار پیوسته حداکثر هر ۲۲ ثانیه تقسیم می‌شود.
۴. «پایان ضبط» میکروفون را خاموش می‌کند و آخرین بخش را برای پردازش می‌فرستد. پس از تکمیل پردازش، متن قابل ویرایش است.
۵. از «کپی متن» یا «دریافت TXT» برای نگهداری نتیجه استفاده کنید. متن با بستن صفحه نگهداری نمی‌شود.

فایل‌های صوتی و بعضی فایل‌های ویدیویی مانند MP4 و 3GP هم قابل انتخاب‌اند؛ حداکثر ۱۰۰ مگابایت. متن فایل‌ها با آماده شدن هر قطعه نمایش داده می‌شود. نتیجهٔ ضبط‌ها و فایل‌های بعدی به متن فعلی افزوده می‌شود؛ برای شروع از صفر «پاک کردن» را بزنید.

## مدل و پردازش

- مدل از مسیر `../.models/faster-whisper-large-v3-turbo` خوانده می‌شود؛ همان مدل بزرگ موجود پروژه، بدون کپی یا دانلود.
- محیط موجود `../.venv` و `faster-whisper` استفاده می‌شوند. سرور پایتون به وابستگی جدید نیاز ندارد.
- پردازش روی CPU با int8 و تشخیص بخش‌های گفتار (VAD) انجام می‌شود. مدل کوچک موجود سریع‌تر است اما معمولاً دقت کمتری دارد؛ مدل SepFormer پروژه برای جداسازی چند گوینده است و برای دیکته با یک میکروفون استفاده نمی‌شود.
- نمایش متن، قطعه‌ای با تأخیر پردازش است، نه نوشتن لحظه‌ای هر کلمه. اگر پردازش از ضبط عقب بماند، ضبط خودکار متوقف می‌شود تا صداهای دریافت‌شده کامل پردازش شوند.
- برنامه فقط به `127.0.0.1` متصل می‌شود. هیچ API ابری، فونت خارجی یا دانلود مدل استفاده نمی‌شود. برای رابط ضبط از Chrome یا Edge به‌روز استفاده کنید.
- فایل موقت صدا پس از پردازش حذف می‌شود و نتیجه تا یک ساعت در حافظهٔ سرور قابل دریافت است؛ متن برای ذخیرهٔ دائمی باید دانلود شود. خاموش کردن اجباری فرایند ممکن است فایل موقت را در پوشهٔ Temp باقی بگذارد.
- دقت متن به وضوح صدا و لهجه بستگی دارد؛ متن نهایی را مرور کنید.

## اجرای دستی

در پوشهٔ پروژه، با PowerShell:

```powershell
& .\.venv\Scripts\python.exe '.\Transcript\app.py'
```

برای پورت دیگر، `--port 8766` اضافه کنید. برای اجرا بدون باز شدن مرورگر، `--no-browser` اضافه کنید. برای پایان برنامه، پنجرهٔ اجرای آن را ببندید یا Ctrl+C بزنید.
